# 0.2.0 — review a pull request without installing anything

_2026-09-02 · 28 commits since [v0.1.0](https://github.com/gwicho38/prview/releases/tag/v0.1.0) (2026-07-23) · 31 files changed, +4005 / −218_

0.1.0 was a local server that drove the `gh` and `claude` CLIs. 0.2.0 adds a hosted
build that needs neither: open a URL, paste a PR, and a code model runs on your own
GPU inside the tab. Nothing is sent to a server, and there is no key to buy.

**https://gwicho38.github.io/prview/**

## Review with no install and no API key

- **The hosted site.** `scripts/build_pages.py` stages the real `core.py`, `order.py`
  and `behaviors.py` into a static build and runs them in Pyodide, so parsing,
  ordering and prompt-building have one implementation and one test suite across both
  builds. Review state lives in `localStorage`; the PR comes from the GitHub API.
- **A model in your browser.** The `in-browser` AI engine runs Qwen2.5-Coder or
  Phi-4-mini through WebLLM on WebGPU, in a worker so the diff pane never freezes.
  Weights download once from the MLC CDN and are then served from the browser cache.
- **Private repositories.** Paste a GitHub token in the bar at the top; it is verified
  against `/user` and attributed to an account before any PR load depends on it. Every
  way GitHub can refuse — invalid token, exhausted quota, secondary rate limit, an
  organisation that needs SSO authorization, a missing scope, a repository the token
  cannot see — gets its own message and its own remedy. The token is sent only to
  `api.github.com`, lives in `sessionStorage` by default, and `Remember on this
  browser` is opt-in.

## Read a PR as a story, not an alphabetical file dump

- Behaviour units are derived from a PR's commits, named by an AI pass that cannot
  re-partition them, and grouped in the sidebar with behaviour-level comments.
- Review order modes, a soft archive for finished reviews, a PR lifecycle badge, and a
  link straight back to the submitted review.
- Diff ergonomics: syntax highlighting, line wrapping, full-file view, and a text
  selection that feeds the Ask box.

## Overview diagrams that describe your PR

The whole-PR Overview asks for before/after and lifecycle diagrams. Its prompt shipped
two fully-worked examples from an unrelated system — 44% of the prompt on a small PR —
and models reproduced them verbatim at every size tested, 1.5B through 7B. The examples
are now slot templates and no slot may survive into the answer. Measured on
`gwicho38/mcli#163`: exemplar copying went from 17 hits to zero.

## Local-only, by necessity

The `claude` engine and everything under Repowise need processes a web page cannot
start, so the hosted build does not offer them. Set the AI engine to `in-browser` there.

## Upgrading

Nothing to do. `pipx upgrade prview` (or `make install`) for the local app; the hosted
build is a URL.
